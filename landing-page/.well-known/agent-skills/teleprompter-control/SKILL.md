# Glance Teleprompter Control Skill

This skill allows autonomous agents to interface with Glance desktop instances or WebMCP browser tools.

## Actions

1. `set_scroll_speed(wpm: int)`
2. `toggle_voice_pause(enabled: bool)`
3. `jump_to_heading(title: string)`
