Smooth presentation overlay on Windows

Glance gives Windows users a clean, distraction-free teleprompter overlay that sits on top of Zoom, Microsoft Teams, Google Meet, or Webex. Stay on message without looking down at physical notes or struggling with secondary monitor placement.

Key Windows features

  • Windows 10 & 11 support: Optimized for all modern 64-bit Windows PC devices and laptops.

  • SmartScreen Guidance: Direct download installer with quick installation verification instructions.
  • Local-first Data: Your speech notes and presentation scripts are stored locally on your device.

Installation & SmartScreen guidance

Because Glance is downloaded directly from our site, Windows Defender SmartScreen may display a standard security prompt upon first launch. Simply click More info, then select Run anyway. You can view full setup guidance on our Windows installation help page.
